# LokaMate

## 📄 Description
LokaMate adalah aplikasi desktop berbasis kecerdasan buatan (AI) yang dirancang untuk menyederhanakan perencanaan liburan Anda di Indonesia. Kami memahami bahwa mengatur destinasi, penginapan, dan transportasi seringkali membingungkan dan menyita waktu. Oleh karena itu, LokaMate hadir untuk merangkum semua informasi tersebut menjadi satu kesatuan yang rapi, praktis, dan mudah digunakan.
## ✨ Fitur Utama
* **Integrasi Informasi Perjalanan:** Menggabungkan pilihan destinasi, akomodasi, dan transportasi ke dalam satu platform.
* **Estimasi Anggaran:** Membantu pengguna memperkirakan biaya perjalanan yang dibutuhkan.
* **Personalisasi Berbasis AI:** Menyusun rencana perjalanan (itinerary) yang disesuaikan dengan kebutuhan dan preferensi pengguna.
