# Lokamate — Perencana Liburan Indonesia

This project was built with [Lovable](https://lovable.dev).

## Build with Lovable

Lokamate menyusun rencana perjalanan Indonesia berdasarkan destinasi, gaya perjalanan, anggaran, dan durasi. Proyek ini dipasang dari arsip pengguna ke workspace Lovable ini.

Lihat `HOSTING.md` untuk opsi hosting lokal dan `DESKTOP.md` untuk panduan aplikasi desktop. Data akun dan itinerary pada workspace ini menggunakan Lovable Cloud; akun dan data dari workspace lama tidak dipindahkan bersama arsip kode.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
